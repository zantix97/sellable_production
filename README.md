# sellable_production


📊 Real-Time Sellable Production Monitoring Dashboard
This project involves the development of an interactive dashboard designed to monitor real-time sellable production against monthly production targets. The dashboard provides a clear visualization of performance by market line, enabling direct comparison between actual production and established goals throughout the month.

It also includes daily tracking to quickly detect and respond to deviations, supporting timely decision-making and helping to optimize operational efficiency.

🔧 Technologies used:

Power BI
SQL (for data extraction)
Scheduled data refresh automation

🎯 Impact:

Improved responsiveness to production deviations
Increased visibility of production performance across market lines
Key tool for real-time operations supervision on the production floor
